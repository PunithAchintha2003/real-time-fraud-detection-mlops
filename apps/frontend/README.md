# Frontend

Next.js frontend for the Real-Time Fraud Detection MLOps platform.

## Pages

/           Welcome page
/register   User registration
/login      User login
/dashboard  Fraud detection dashboard and transaction history

## Responsibilities

- Register and login UI
- Store JWT access token locally for development
- Call NestJS backend gateway
- Display fraud prediction result
- Display transaction history

## Local Setup

npm install
cp .env.example .env.local
npm run dev

## Environment Variables

See .env.example.
